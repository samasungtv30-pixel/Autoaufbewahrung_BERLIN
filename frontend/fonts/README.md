# Local Fonts

Inter (variable weight 100-900) and Space Grotesk (variable weight 300-700)
are served locally as WOFF2 files. Latin is preloaded; Latin Extended is
requested only when its characters are needed. German umlauts and sharp S
are included in the Latin subset.

Sources: Google Fonts CSS API, downloaded 2026-08-30.

- https://fonts.google.com/specimen/Inter
- https://fonts.google.com/specimen/Space+Grotesk

Both families use the SIL Open Font License. Keep `inter-OFL.txt` and
`space-grotesk-OFL.txt` alongside the fonts when redistributing them.
The public site makes no requests to Google Fonts.
